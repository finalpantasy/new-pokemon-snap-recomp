# Option map

Every player option and where it lives: the launcher page, the F1 menu tab and section, the tab of the game's own Settings screen, and the `--set` key ([command-line.md](command-line.md)). Generated by `python -I scripts/ui/option_audit.py --md docs/option-map.md`; the script also fails when a native row has no help line, no `--set` key or the wrong restart note.
